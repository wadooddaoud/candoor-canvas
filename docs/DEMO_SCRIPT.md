# Demo video script — target 2:45

## 0:00–0:20 — The problem

**Narration:** Career advice breaks when context breaks. AI can rewrite a sentence, but it rarely shows its reasoning, waits for permission, or prepares the next human to help. Candoor Canvas turns that fragmented process into one visible collaboration.

**On screen:** Title card, then land on the hero and judge prompt.

## 0:20–1:35 — Live WebMCP loop

**Narration:** The candidate is targeting a Senior Product Manager role in AI platforms. The agent reads the live canvas through WebMCP, identifies a weak bullet, and places the evidence gap directly beside it. It proposes a stronger version—but the accepted resume and impact score do not change yet. The human stays in control. When they accept, the same shared reducer applies the edit and recalculates the score from visible rules.

**On screen:** Read state, diagnose b1, propose b1, pause on before/after diff, click Accept, show score increase and event rail.

**Narration:** Next, the agent ranks fictional demo advisors against the remaining executive-storytelling gap. Every result includes a match reason, and the candidate chooses who feels right.

**On screen:** Scroll to advisors, invoke match, show reordered cards, select Maya.

## 1:35–2:10 — Human handoff

**Narration:** One more tool stages the handoff. It packages the goal, accepted changes, deterministic score, remaining gaps, and a practical agenda. This is a preview—not a booking. Nothing touches authentication, private advisor data, or Candoor production.

**On screen:** Open handoff modal, highlight score, agenda, safety note, and Copy brief.

## 2:10–2:40 — Architecture and trust

**Narration:** Six imperative WebMCP tools and every manual control call the same typed application actions. Inputs use strict schemas and runtime validation. Tool-supplied score deltas are impossible, registration cleans up with an abort signal, and browsers without WebMCP retain the full manual experience.

**On screen:** Architecture diagram, code/tool registry, test results.

## 2:40–2:50 — Close

**Narration:** AI finds the signal. You decide what ships. Humans take it further. That’s Candoor Canvas.

**On screen:** Branded outro with live URL and repository URL.
